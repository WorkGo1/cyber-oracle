# 赛博神婆 · Vision

> **读者：** 想理解「这个产品最终为谁创造什么」并导航产品地图的人。
> 主线是用户旅程与结果，不是技术模块目录。

---

## 产品核心

**赛博神婆（暂名，候选见下）** 是当代年轻人（约 1998–2005 出生，以 00 后打工人/学生为主）的 **"赛博防内耗指南 & 情绪投射镜"**。

- **为谁：** 被班味浸泡、在职场/暧昧/消费里反复内耗的年轻打工人与学生；他们不信传统神秘学黑话，但需要低成本的仪式感来安放情绪、辅助微小决策。
- **什么结果：** 抽一张牌 → 3 分钟内获得"讲人话、带梗、共情、可操作"的解读，情绪被接住（治愈）或被点醒（毒舌），并把这份体验变成可发社交平台的高颜值卡片。
- **最小本质：** 塔罗只是载体，**情绪价值 + 人话翻译 + 现实小建议（Action Item）** 才是产品；仪式感（洗牌/切牌/翻牌的物理动效与音效）是让用户"信"的包装。

**调性红线：** 拒绝晦涩传统术语（"圣杯三逆位预示..."这类话不出现）；人话 + 互联网热梗 + 心理学共情；毒舌但不伤人，治愈但不灌鸡汤。

## 用户怎样获得结果（旅程主线）

1. **清晨通勤 · 今日班味运势** — 打开首页 → 每日免费抽 1 张 → 得到"班味指数 + 宜/忌 + 扎心但治愈的行动指引" → 生成壁纸级卡片保存/发圈。
2. **职场内耗时刻 · 潜台词翻译器** — 老板说了句怪话 → 输入原话 → 抽 3 张 → 得到"表面态度 / 深层潜台词 / 高情商应对" → 追问"那我该怎么回？"。
3. **深夜恋爱脑 · Crush 意图探针** — 对象已读不回 → 抽 3 张（他现在的状态 / 对你的真实感受 / 走向与阻碍）→ 选"毒舌闺蜜"人格要一盆清醒冷水。
4. **纠结星人 · 决策天平** — "要不要买这件衣服 / 要不要去这个局" → 输入 A/B 选项 → 抽 1 张 → 得到倾向支持率 + 风险点提示，像赛博抛硬币。
5. **摸鱼共鸣 · 能量树洞** — 抽完牌把一句吐槽/祝福匿名扔进池子，或捞出别人的卡："全国还有 N 人今天抽到了宝剑十，你不是一个人在熬。"

每个旅程共享同一条核心链路：**选场景 → 选 AI 人格 → 洗牌/切牌/翻牌（仪式感）→ 解读 → 多轮追问（1~3 轮）→ 生成分享卡片**。

## 能力怎样支撑旅程（能力版图）

- **牌库与抽牌引擎** — 78 张韦特塔罗数据（正/逆位）、洗牌、切牌、随机正逆位；支撑全部旅程。深入：Epic 001 / 牌库数据。
- **解读引擎（双轨）** — 本地规则引擎（内容化解读，离线可用、零成本、稳定）+ 可选 LLM 适配器（OpenAI 兼容 API，用户自配 key，动态生成与追问）；默认本地轨。深入：Epic 001 解读引擎。
- **AI 人格系统** — 毒舌嘴替闺蜜 / 温柔治愈大姐姐·猫猫 / 硬核职场军师 / 神秘赛博巫师；同一牌面 × 不同人格 × 不同场景 = 不同话术风格与建议视角。深入：Epic 001 人格系统。
- **场景矩阵** — 每日解压（班味运势、能量签）· 职场生存（潜台词翻译器、离职二选一、摸鱼吉凶）· 情感救赎（Crush 探针、清醒符/断联）· 决策天平（赛博抛硬币）· 社交共振（树洞、合盘）。MVP 先做核心四场景，见 Epic 边界。
- **仪式感系统** — 翻牌物理动效（framer-motion）、程序化音效（Web Audio，无需音频资源）、手机震动（Vibration API）。
- **分享生成器** — Canvas 手绘拍立得风卡片：顶部塔罗视觉 + 中部加粗人设关键词（"今日人设：人间清醒打工魂"）+ 底部金句；导出 PNG。
- **能量树洞** — MVP 为本地模拟池（明确标注"离线演示数据"），后续接服务端实现真实匿名共鸣。
- **抽牌历史** — localStorage 持久化每日记录，支撑"每日一抽"限制与回顾。

## 边界、候选与现实差距

- **定位边界（跨区域原则）：** 娱乐与情绪价值产品，不是心理咨询；结果页固定展示免责声明。不生成医疗/法律/投资建议。用户输入出现自伤等危机信号时，中断解读并展示心理援助热线信息。
- **隐私边界：** 默认一切数据存本地（localStorage）；LLM 功能由用户主动配置 API 才启用，问题文本仅发往用户配置的端点。不做账号体系（MVP）。
- **内容边界：** 牌意全部使用原创现代语境解读；大阿尔卡纳深度撰写，小阿尔卡纳用「花色 × 数字」结构化组合生成，避免 78×人格×场景 全量手写。
- **仍探索或互斥的方向：**
  - 视觉风格：**Y2K 赛博酸性风（已选定 MVP 主风格）**；复古黑白插画风、极简莫兰迪治愈风为候选（可演进为"主题切换"能力）。
  - 双人合盘（塑料同事羁绊值/灵魂合拍度）：候选，需服务端或点对点链接，MVP 不含。
  - LLM 调用方式：浏览器直连（MVP）vs 服务端代理（正式化时切换）。
  - 产品名：赛博神婆（暂定）/ 电子塔罗馆 / 班味研究所 / 今日不内耗。
- **实现程度与 Epic / Spec 链接：**
