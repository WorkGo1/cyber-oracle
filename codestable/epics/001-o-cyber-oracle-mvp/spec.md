## 这条线要改变什么

从空项目建成一个可发布、可手机访问的**塔罗占卜 Web 应用 MVP**：核心四场景 + 四人格解读 + 仪式感动效 + 分享卡片 + 本地树洞，全程无后端、开箱即用。

- 来源 Vision：`codestable/vision/index.md` — 摘取「核心链路 + 四场景 + 双轨解读引擎 + 仪式感 + 分享生成器 + 本地树洞」；**故意不在边界内**：双人合盘、真实服务端树洞、账号体系、主题切换（多风格）、离职二选一/摸鱼吉凶等长尾场景（列入后续 Epic 候选）。

## 当前怎么理解（活规格）

### 技术方案

- **栈：** Vite + React 18 + TypeScript + Tailwind CSS 3 + framer-motion + zustand + react-router-dom。
- **无后端：** 数据全在代码与 localStorage；LLM 走浏览器直连 OpenAI 兼容 API（用户在设置页自配 baseUrl / key / model），失败自动降级本地轨。
- **零媒体资源依赖：** 音效用 Web Audio 程序化合成；牌面视觉用 SVG 程序化绘制（统一牌背模板 + 每张牌独立符文构图），不依赖外部图片。
- **视觉风格：** Y2K 赛博酸性风（深底 + 酸性荧光绿/紫/粉、铬金属质感、扫描线、像素点缀）。设计规范由 ui-ux-pro-max 技能产出后固化进 design tokens。

### 场景规格（MVP 四场景）

| 场景 | 输入 | 牌阵 | 输出结构 |
|---|---|---|---|
| 班味运势（每日一抽） | 无输入 | 1 张 | 班味指数 55–95%（含文案如"75% 易被甩锅"）· 宜×2 / 忌×2 · 行动指引一句 |
| 潜台词翻译器 | 一句职场话术（≤100 字） | 3 张：表面态度 / 真实潜台词 / 应对建议 | 三段解读 + 高情商回复示例 |
| Crush 意图探针 | 可选：对方行为描述 | 3 张：他现在的状态 / 对你的真实感受 / 走向与阻碍 | 三段解读 + 一句话判词 |
| 决策天平 | 一个"要不要 X"问题 | 1 张 | 倾向支持率 % + 风险点 + 一句话裁决（赛博抛硬币） |

- 每日一抽按本地日期限 1 次；再抽引导去其他场景或看历史。
- 每个场景抽完后支持**深潜**：快捷追问按钮（按场景定制，如"那我该怎么回他微信？""今天能准点下班吗？"）+ 自由输入，限 3 轮。

### 解读引擎（双轨）

- **本地轨（默认）：** 内容即数据——大阿尔卡纳 22 张深度撰写（关键词池 × 场景映射 × 人格语气片段），小阿尔卡纳 56 张按「花色 × 数字」结构化组合。输出 = 牌面定调一句 + 现状剖析 + Action Item + 幸运补给彩蛋，按人格模板拼装。
- **LLM 轨：** Prompt 结构 = Role（人格）+ Context（用户问题/牌面/正逆位/场景）+ Task + Output Requirements（对应 Vision 的模板），走流式或整段返回；任何错误静默降级本地轨，不阻塞用户。
- **人格 4 选 1：** 毒舌嘴替闺蜜 / 温柔治愈大姐姐·猫猫 / 硬核职场军师 / 神秘赛博巫师；决定语气、建议视角、彩蛋风格；默认按场景推荐。

### 安全与边界（继承 Vision）

- 结果页固定免责声明（娱乐向、非心理咨询）。
- 用户输入命中自伤/危机关键词 → 中断解读，展示心理援助信息（全国 24 小时心理援助热线 12356）。
- 不输出医疗/法律/投资建议；LLM 轨 system prompt 中同样约束。

### 长期质量约束

- **兼容性：** 移动优先（375px 基准），桌面自适应；Chrome/Edge/Safari 近两年版本。
- **性能效率：** 动效仅用 transform/opacity 保持 60fps；首屏包体克制（解读内容按场景懒加载可接受）。
- **易用性：** 选场景→抽牌→出解读 ≤ 3 步主操作；触控目标 ≥ 44px。
- **可靠性：** LLM 失败/超时不白屏，降级本地轨；本地轨永远可用。
- **信息安全：** API key 只存 localStorage；除用户自配端点外无任何网络上传。
- **维护性：** 解读内容（data）与引擎（logic）分离，新增场景不改引擎。
