# 脚手架与设计基座

## 做成以后是什么样

`npm run dev` 启动后浏览器打开一个 Y2K 赛博酸性的应用壳：顶部品牌条 + 底部 Tab 导航（首页/记录/设置），页面骨架可路由跳转，设计 tokens（色彩/字体/间距/圆角/发光效果）已固化并在壳上可见，音效与震动工具函数就绪。

**范围：** 包含脚手架、Tailwind 配置与 tokens、路由骨架、布局壳、Zustand store 骨架（人格/设置/历史）、Web Audio 音效工具、震动工具；不包含任何业务场景与牌数据。

**归属：** Epic 001。UI 视觉遵循 `.agents/skills/ui-ux-pro-max` 产出的设计规范（执行前先加载该技能产出规范）。

## 为什么现在做 / 当前坏在哪

空项目，一切的地基；tokens 与壳先行避免后续返工。

## 动哪些、验哪些

- 必须改：新建 `web/`（或项目根）Vite 工程、`src/design/` tokens、`src/stores/`、`src/lib/`（audio/haptics）、路由与壳组件。
- 需要验：dev server 启动无报错；tokens 在壳上视觉生效；音效函数播放一个合成音；移动端视口下壳布局正常。

## 验证

`npm run dev` + 浏览器查看壳页面；`npm run build` 无 TS 错误。

## 执行记录

- 2026-09-06：手写 Vite+React18+TS+Tailwind3 脚手架（npm 镜像源，Node 22）；tokens 固化进 `tailwind.config.ts` + `src/index.css`（CSS 变量 RGB 三元组）；Zustand persist store；HashRouter 应用壳（顶品牌条+底 4Tab）；`lib/audio.ts`（Web Audio 合成 5 种音效）与 `lib/haptics.ts`。字体走 @fontsource 本地打包（Orbitron/JetBrains Mono/ZCOOL QingKe HuangYou），不依赖 Google CDN。
- 验证：build 通过；首页截图通过视觉验收；音效/震动函数就绪。
