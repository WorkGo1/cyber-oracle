# 分享卡片与能量树洞

## 做成以后是什么样

结果页「生成我的赛博神签」按钮 → Canvas 绘制拍立得风卡片（深底 + 牌面视觉 + 加粗人设关键词如"今日人设：人间清醒打工魂" + 金句 + 品牌角标）→ 可长按/下载 PNG。能量树洞页：扔一句匿名吐槽/祝福进池子、随机捞一张别人的牌（带"全国还有 N 人今天抽到 X"共鸣文案），页面标注"离线演示池"。

**范围：** 包含 Canvas 卡片生成器（多尺寸适配 1080×1440）、树洞页与本地模拟池（40+ 种子内容）、localStorage 记录用户扔过的纸条；不包含真实服务端。

**归属：** Epic 001。

## 方案与实现安排

- Canvas 手绘（不用 html2canvas，避免 DOM 依赖）：字体用系统栈，牌面视觉用简化版符号重绘。
- 共鸣计数 = 种子基数 + 当日日期哈希偏移，页脚注明演示数据。

## 验证

四场景各生成一张卡片并下载，图片内容完整不糊；树洞扔/捞循环正常；演示标注可见。
