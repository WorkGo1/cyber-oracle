# 场景页面与核心链路

## 做成以后是什么样

首页是五宫格场景矩阵（四场景 + 能量树洞入口）；每个场景走通「选场景 →（输入）→ 选人格 → 仪式抽牌 → 解读结果页（含深潜追问 3 轮）」；每日一抽按日期限次；结果页有免责声明，危机输入展示援助信息。

**范围：** 包含首页矩阵、四场景流程页（按 Epic spec 场景规格的输入/牌阵/输出结构）、人格选择器、结果页与深潜对话、每日限次、历史记录页（今日/往期）；不包含分享卡与树洞（Issue 006）。

**归属：** Epic 001。输出结构与 Vision 旅程一一对应。

## 方案与实现安排

- 场景注册表模式：每场景一个配置（id/名称/梗文案/输入类型/牌阵/输出插槽/快捷追问），页面由通用流程引擎驱动，新增场景不改框架。
- 状态流：`idle → input → persona → ritual → reading`，用 zustand 保存当前会话，刷新后回到首页。
- 深潜：快捷按钮 + 自由输入；本地轨用意图关键词匹配 + 牌面上下文模板作答；LLM 轨续聊。

## 验证

四场景全链路手测：输入校验、人格切换影响文案、深潜 3 轮限制、每日一抽次日重置（改系统日期或清缓存验证）、免责声明与危机路径展示。
