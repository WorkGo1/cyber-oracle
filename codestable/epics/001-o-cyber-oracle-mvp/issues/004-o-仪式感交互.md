# 仪式感交互

## 做成以后是什么样

抽牌前三段式仪式：**洗牌**（牌堆飞舞洗乱，点按或摇一摇驱动）→ **切牌**（选一叠位置）→ **翻牌**（点击牌背逐张 3D 翻转）；全程有 Web Audio 合成音效（沙沙声/切牌声/翻牌啪）+ 移动端震动反馈；设置页可静音。

**范围：** 包含洗牌/切牌/翻牌交互组件与动效编排、音效合成器扩展、震动调用、动效可跳过（长按或"跳过仪式"）；不包含场景业务逻辑。

**归属：** Epic 001。

## 方案与实现安排

- framer-motion 仅用 transform/opacity；牌堆用绝对定位 + spring。
- 音效：Web Audio 噪声/振荡器合成三类音（shuffle whoosh、cut snap、flip click），封装到 `lib/audio.ts`。
- 震动：`navigator.vibrate` 按事件给 10–30ms 短震；不支持时静默。

## 验证

手机端与桌面 Chrome 各走一遍仪式：动画流畅无跳帧；静音开关生效；跳过仪式直接出结果。
