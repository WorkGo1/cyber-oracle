# 解读引擎与人格系统

## 做成以后是什么样

输入「场景 + 人格 + 已抽牌面」即可得到结构化解读（牌面定调一句 / 现状剖析 / Action Item / 幸运补给彩蛋，或场景自定义结构）；默认本地轨离线可用；配置 LLM 后走 API 动态生成并支持追问。

**范围：** 包含本地解读内容（22 张大阿尔卡纳深度文案 + 花色×数字组合模板 + 场景模板 + 人格语气片段 + 宜/忌池 + 彩蛋池）、4 人格定义（含 LLM system prompt）、LLM 适配器（OpenAI 兼容 /chat/completions、超时与降级）、危机关键词守护；不包含 UI 页面（Issue 005）。

**归属：** Epic 001。内容调性对照 Vision「调性红线」：人话 + 热梗 + 共情，拒绝术语黑话。

## 方案与实现安排

- 内容与引擎分离：`src/content/`（牌意、场景模板、人格片段）为纯数据；`src/engine/` 为拼装逻辑。
- 每个场景定义输出插槽；本地轨按牌 → 场景插槽 → 人格语气三层拼装，随机池用抽牌种子保证同一次抽牌多轮渲染一致。
- LLM 轨：`llmChat(messages, config)`，system prompt 按「人格 × 场景 × 牌面」生成；2 超时/错误降级本地轨并在结果标注"本地解读模式"。
- 危机守护：正则命中自伤类关键词 → 返回 crisis 结果类型，页面据此展示热线信息。

## 验证

固定种子下四场景 × 四人格各出一份解读，人工检查：无传统术语、结构完整、风格差异明显；断网/错误 key 时降级路径生效。
