# 牌库与抽牌引擎

## 做成以后是什么样

78 张韦特塔罗数据（22 大阿尔卡纳深度 + 56 小阿尔卡纳结构化）可被洗牌/切牌/抽 N 张（随机正逆位）；每张牌有程序化 SVG 牌面（统一模板 + 独立符文构图）与统一牌背。

**范围：** 包含牌数据模型、洗牌引擎（Fisher-Yates）、正逆位（约 30% 逆位）、切牌仪式逻辑、SVG 牌面组件（正/逆位渲染）；不包含解读文案（Issue 003）与场景页面。

**归属：** Epic 001。

## 为什么现在做

抽牌是全产品唯一公共依赖；数据与视觉先行，解读引擎才能对牌写作。

## 方案与实现安排

- 大阿尔卡纳条目：id/名称/别名梗称/正逆位关键词池/象征意象。
- 小阿尔卡纳：花色（权杖=事业内卷 / 圣杯=情绪恋爱 / 宝剑=精神内耗 / 星币=金钱身体）× 数字原型（ACE 新开始、三=小团体、五=冲突、十=压垮…），组合生成数据而非手写 78 份。
- 牌面 SVG：主题化边框 + 罗马数字 + 核心符号（用几何图形与符文字符组合），逆位 = 正位 rotate(180deg)。

## 验证

单元快照：随机种子固定时抽牌结果可复现；渲染一张大阿尔卡纳与一张小阿尔卡纳牌面目测符合 Y2K 风格；逆位渲染正确。
